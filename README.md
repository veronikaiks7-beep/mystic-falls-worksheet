# 🦇 The Mystic Falls Upper East Side Chronicles 🗽

An interactive ESL worksheet for a 10th-grade student (Upper-Intermediate).
Based on Solutions Upper-Intermediate, Introduction Unit C.

## 🎯 Topic
Talking about family and life events.

## 🎨 Aesthetic
Inspired by "Gossip Girl" and "The Vampire Diaries" (Dark Academia, Mystic Falls vibes).

## 🛠️ Features
- Interactive dropdowns and text inputs.
- Self-check button for students.
- Printable PDF version (buttons and answer keys are hidden when printing).
- Teacher's Answer Key included.

## 🚀 How to use
Simply open the `index.html` file in a web browser, or visit the GitHub Pages link.
